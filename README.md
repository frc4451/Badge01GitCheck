# Badge 01 Git Check

## Goals
As part of the GarageDocs Curriculum, Badge 01 recipients will establish
GitHub accounts and learn how to use Git for regular workflows in software development.

This means that students will need to learn how to do the following:
1) Make forks of a source repository
2) Clone their fork of the source repository
3) Make their own branch within their fork repository
4) Make their own pull requests from their fork repository to the source
5) Go through code review with mentors and senior students
6) Have their code approved, merged, and deployed to this repository


## Steps for Badge 01 Students
1) Make a Fork of this repository
2) Clone your Fork repository
3) Make a branch called `whoami_submission`
4) Open the `responses` subfolder in this repository
5) Create a file called `<your_name>.md`, and answer the following questions
    1) Who are you?
    2) What is a fun fact about you?
6) Make sure that you follow proper Markdown syntax so it displays well on the GitHub site
7) Push your branch to GitHub under your forked repository
8) Open a Pull Request to this source repository
9) Notify either the Automation Mentor or the Automation Student Lead for review. The reviewer may suggest fixing typos, they will add comments. If they 
do, please update your commit as necessary
10) Mentor or Student Lead will review, approve, and merge

Assuming all steps have been completed, you will have completed the Git assignment for Badge 01.
